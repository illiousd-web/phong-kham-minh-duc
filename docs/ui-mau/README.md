# Mẫu giao diện đã chốt (A+C: Liquid Glass + Android 17 Expressive)

Nguồn chuẩn để làm giao diện. Ảnh PNG = hình phải đạt; file .html = mã CSS gốc (lấy đúng màu, bo góc, đổ bóng, kích thước chữ từ thuộc tính style).

| File | Màn |
|---|---|
| KetHop | Tiếp đón (1366) |
| KH_Kham | Bác sĩ khám (1366) |
| KH_KeDon | Kê đơn (1366) |
| KH_XetNghiem | Nhập kết quả xét nghiệm (1366) |
| KH_ThuNgan | Thu ngân (1366) |
| KetHopDT | Bác sĩ trên điện thoại (390) |
| QuyChuan | Quy chuẩn: nút, màu, bo góc, kính |
| TrangThai | Trạng thái đặc biệt |

Số liệu, tên người trong mẫu là giả lập. Mục menu/tính năng chưa có trong phần mềm (Lịch hẹn, Khám đoàn, Mẫu nhanh…) không làm giả; chỉ giữ hình thức.
